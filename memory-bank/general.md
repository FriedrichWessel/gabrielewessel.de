# Project Purpose 

The purpose of this project is to create a simpel single page website for gabriele wessel

# General Project Structure 

## Folder 
src/
 - this contains the actual structure for the website 
sources/
    this folder contains all design and content source files which should be
    used as input for the website programming and design
  -asset/
    this contains the images that can be used on the website ( copy to the src/assets folder when used)
  -design_sources/
    this contains design references 
memory-bank/
    this contains instructions for the web-designer

# Guidelines

The webpage should be modern in tech and design. 

All Design decision must follow the given flyer pdf
All content must be used from side_content.md
All references images must be used from sources/assets

## Technical details 
 The page should be responsive and mobile ready
 use matching open google fonts ( close match to whats in the PDF )
 use modern web tech 
 should not require a running server ( single page html + css and if needed javascript)
 use bootstrap for design 

 ## Design Details 

 * Fonts in the flyer a non-web ready - find good matching google fonts
